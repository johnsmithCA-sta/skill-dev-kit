| 1.7.1 | 2026-08-29 | 评测循环更可信：无产物时明确提示待补数据而非给出误导性低分；重跑产物后自动刷新评分，评测缓存与产物保持一致 |
| 1.7.2 | 2026-08-29 | 门禁降噪与口径升级：① 发布预检自动豁免技能自身名与 CSS 媒体查询前缀的「疑似密码格式」误报，第三方锁定/压缩文件默认跳过并留痕——strict 模式告警信噪比大幅提升，可直接接入 CI；② 触发词评估新增 --from-description 口径（对应平台真实路由行为），与正文触发词口径双轨判读；技能无触发词章节时给出明确指引而非静默降级；③ 新增「知识产权边界与护城河判定」方法论：第三方受限内容反向检查、随包文档去留两检验、护城河三要素、对外文档双轨制（README/版本说明以功能与独创性为主）、干净历史重发纪律；发布检查清单同步强化第 9/16 项，踩坑表扩充至 12 条 |
