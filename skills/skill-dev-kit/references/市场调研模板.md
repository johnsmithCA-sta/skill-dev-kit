# 市场调研模板（轻量化 · 发布前必做）v1.1

> 本模板固化为 `skill-dev-kit` 标准资产。任何技能发布前套用本模板即可，无需重新设计调研方案。
> 核心约束：**只调研市场规模最大的前 5 家，不做全量普查。**
> 产出深度参考范本：《privacy-audit-独创性与商业竞争力评估报告.md》第 2–5 章写法（调研表→生态格局结论→独创性分析→商业竞争力速评→结论先行）。

## 0. 产出总览（调研后必须交付 5 份固定件）

| # | 固定件 | 对应范本章节 |
|---|---|---|
| 1 | 调研对比表（Top5，每家一行） | 第二章 |

| 3 | 独创性分析（2–3 个维度 × 对比表 + 独特点结论） | 第三章 |

## 1. 目的

发布前快速定位市场空白与差异化机会，**不做全量普查**。只回答两个问题：

1. 我的技能相对头部竞品，差异点在哪里（能否一句话讲清定位）？
2. 是否存在明显重复 / 红海，需要规避或重新定位？

## 2. 调研对象选取规则（固定 · 不可突破）

- **唯一规则**：在目标领域（同类技能 / 竞品）内，按 **市场规模** 排序，取 **最大的前 5 家**。
- **规模排序依据**（按可获得性依次降级，取最先可用的口径）：
  1. 平台官方下载 / 安装 / 使用次数
  2. 评分 × 评论数（加权热度）
  3. 平台官方精选 / 编辑推荐 / 榜单排名
  4. 最近更新频率与活跃度
  5. 被其他技能引用 / 依赖次数
- **数据缺失兜底**：若平台不提供规模数据，退化为「全站分类 Top5 + 官方精选」，并在对比表注明「规模数据缺失，按头部近似」。
- **硬上限**：无论何种情况，只调研 **5 家**。全量普查（如原 240 样本做法）一律作废。
- **名单指定权**：Top5 具体名单可由用户 / 数据指定；若未指定，按上述规则自动确定。

## 4. 生态格局结论（固定三段式，仿范本第二章）

调研表填完后，必须输出 3 条编号洞察：

1. **主流定位**：Top5 共性——"主流生态的 X 技能几乎全部是「A 定位」"；
2. **稀缺 / 空白**：Top5 中无人做的定位类型——"「B 定位」类极度稀缺：Top5 中仅 <N> 家"；
3. **最重要发现**：机会点一句话——"『<C>』在调研生态中未发现直接竞品——这是本次调研最重要的发现"。

> 模板句：主流生态的 <领域> 技能几乎全部是「<定位A>」；「<定位B>」类极度稀缺：Top5 中仅 <N> 家；"<C>"在所有生态中未发现直接竞品——这是本次调研最重要的发现。
> 若 Top5 无空白点（红海信号），第 3 条改为"本品需重新定位，理由：<证据>"。

### 6.2 可替代性

分三类分析，每类给一句结论，最后汇总一句：

- **低端替代**（脚本 / 通用工具）：<差距点>——替代不了"<本品核心产出>"。
- **高端替代**（专业服务 / 顾问）：<成本 / 定位差异>——本技能定位为<低成本预筛层 / 互补关系>。
- **工具替代**（相邻框架 / 平台能力）：<差异点>——相邻工具，互补而非竞争。
- **汇总句**：在"<细分定位>"上 <无直接替代品 / 有 N 家直接竞品（红海信号）>；通用<X>是相邻赛道。

### 6.3 市场空白与时机

- **空白确认**：逐生态列举证据（"<生态A>已上架均为<X>，<Y>类 0 个；<生态B>唯一<Z>锚定<法域>"）→ 结论"<定位> = <全生态空白点 / 红海>"。
- **时机利好**：列出 2–3 个时间点 / 事件（新规实施、平台活动、生态扩容），说明需求进入爆发期。

### 6.4 变现潜力

- **计费适配**：<技能形态> 天然适配 <计费模式>（一次使用 = 一次计费 / 订阅），且无持续成本（纯本地 / 无需外部服务）。
- **增值路径**：① 企业定制版 ② 与<关联工具>组合为<组合卖点> ③ 垂直深耕 <场景 1/2/3>。
- **局限性**（辩证，必须写）：低频高价值 / 生态成熟度制约 / 付费习惯培养期。

## 8. 硬约束与预算

- 只调研 **Top5**；每家 ≤ 1 次调研；扩展须经人工确认并记录理由。
- 数据缺失必须注明兜底口径（见 §2），不得隐瞒。
- 全程本地调研（公开页面 / 注册表 / 文档），不外泄任何敏感信息。

## 9. 用法

1. 复制本模板到技能 `references/` 或工作区。
2. 按「规模排序依据」确定 Top5 名单（§2）。
3. 逐家填对比表（§3，每家 ≤ 1 次）。
4. 依次产出 5 份固定件（§4–§7）：生态格局结论 → 独创性分析 → 竞争力速评 → 结论。
5. 调研结论作为 SKILL.md / 发布说明的「市场定位」依据，纳入发布前 12 项清单的参考输入（定位不清则重新调研）。
6. 产出可对照范本《privacy-audit-独创性与商业竞争力评估报告.md》第 2–5 章自查深度是否达标。
